# Chapter-specific and conditional canon rules

This file stores instructions that are true only while their stated conditions
remain true. They must be re-evaluated after later canon developments rather
than promoted into permanent global workflow rules.

## Maintenance

- Record the subject, current rule, condition that could supersede it, and its
  source chapter/instruction when known.
- Preserve old states as history when canon changes; update current derived data
  rather than pretending the earlier state was never true.
- If a later chapter appears to satisfy a transition condition, ask the user
  when the text does not confirm it unambiguously.

## Current title and identity rules

- **Lorenah Dayne:** use `Lady Lorenah` / `Leydi Lorenah`, not Princess. If her
  marriage to Jace actually occurs and canon grants the corresponding royal
  style, update this rule and all current display data at that time; a plan,
  betrothal, implication, or theory is insufficient.
- **Rhaella:** `Princess Rhaella` / `Prenses Rhaella`.
- **Leo:** `Lord Leo`, not Prince.
- **Cordin:** `Maester Cordin` / `Üstat Cordin`, not Grand Maester.
- **Baelor:** `Grand Maester Baelor` / `Yüce Üstat Baelor`.
- **Naela Targaryen and Naella Velaryon:** distinct characters despite similar
  names.
- **Cloudgazer:** female; use she/her in English prose and linked current data.

## Current Chapter XX ambiguity rules

- Jace and Saera thinking of Meraxes does not identify the white dragon as
  Meraxes. Do not add a Chapter XX Meraxes appearance.
- Do not assign the unknown white dragon an existing identity merely to satisfy
  the appearance model. Use an unknown/unnamed representation only if the data
  model supports it without inventing canon.
- Vhaemys's interaction with the white dragon is suggestive, not a confirmed
  claim or rider bond. Do not set a rider until canon confirms it.
- A reported Dragonstone silhouette is not a physical dragon appearance.
- Visenor may connect the Dorne fire to Boneskin without knowing Rhaella's fate.
- Vhaemys's conclusions about Baelenys and Jaery are her interpretation, not
  narrator-confirmed family truth.
- Leo's search does not establish that he found a document.
- Gaelor is considered for the Essos party but is not yet a confirmed member.
- Visenor and Leo have agreed in principle to travel to Dorne but have not yet
  begun that journey.

## Manual-only editorial decisions

- **Quotes:** the user chooses which lines enter `data/quotes.json`; never infer
  a quote list as part of the automatic full workflow.
- **Book of Brothers:** add only genuinely major deeds. Ask the user before
  adding a deed whose historical importance is debatable.
