# Chapter-specific and conditional canon rules

This file stores instructions that are true only while their stated conditions
remain true. They must be re-evaluated after later canon developments rather
than promoted into permanent global workflow rules.

## Maintenance

- Record the subject, current rule, condition that could supersede it, and its
  source chapter/instruction when known.
- Preserve old states as history when canon changes; update current derived data
  rather than pretending the earlier state was never true.
- If a later chapter appears to satisfy a transition condition, ask the user
  when the text does not confirm it unambiguously.
