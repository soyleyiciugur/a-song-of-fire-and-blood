# Active Location artwork

Add WebP files here; the play page selects them by the active location card ID:

- `dragonstone.webp`
- `kings-landing.webp`
- `oldtown.webp`
- `default.webp` (when no location is active)

Use a wide composition, with the main visual toward the right. The UI supplies
an independent dark gradient from the left and renders the label, name and
rules over it. Missing images retain the dark base background.
